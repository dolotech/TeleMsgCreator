    遇到问题？
    
        
    
          报 “chat not found” / 找不到会话
          
    八成是机器人还没进频道。打开频道 → 管理 → 管理员 → 添加你刚才创建的机器人 → 勾选「发布消息」。
          私有频道请改用 -100 开头的数字 ID。
    
        
    
        
    
          报 “not enough rights” / 没有权限
          
    机器人已经是成员但没有发帖权限。回到管理员设置，确认勾选了「发布消息」。
    
        
    
        
    
          按钮点了没反应
          
    只有「跳转链接」和「复制文本」按钮不需要后端。回调（callback_data）按钮需要你的机器人程序
          接收 callback_query；本工具只负责发送，不处理点击。
    
        
    
        
    
          图片发不出去
          
    图片需 ≤ {{ limits.photo_mb }} MB，宽 + 高 ≤ 10000 像素，长宽比 ≤ 20:1。
          网络图片必须是直链，不能是网页地址。
    
        
    
        
    
          相册为什么不能加按钮
          
    这是 Telegram 的限制，不是本工具的问题：album 一律不支持 inline keyboard。
          想两者兼得，可以发相册后再补一条带按钮的消息。
