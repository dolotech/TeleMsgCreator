TeleMsgCreator 使用说明
======================================================================

一、最简三步
----------------------------------------------------------------------
1. 把整个文件夹解压到**有写权限**的位置，例如桌面或 D:\TeleMsgCreator。
   不要放在 C:\Program Files 下面（那里普通用户没有写权限）。

2. 双击 start.bat
   浏览器会自动打开 http://127.0.0.1:8765，第一次会弹出引导，
   按提示把 Bot Token 填进去即可。

3. 用完关掉那个黑色命令行窗口，服务就停了。也可以双击 stop.bat。

**本程序自带 Python 运行时，你的电脑不需要装 Python，也不会修改系统设置。**
想卸载的话，直接删掉整个文件夹即可（不留任何注册表项）。


二、其他几个文件是干什么的
----------------------------------------------------------------------
start.bat        启动程序并自动打开浏览器
stop.bat         停止在后台运行的程序（窗口已经关了就无需执行）
doctor.bat       环境自检。程序跑不起来时先双击它，会逐项说明哪里有问题
edit-config.bat  用记事本编辑配置文件
.env.example     配置模板
data\            程序运行时产生：数据库、上传的图片、日志（都在这个目录里）
python.exe 等    自带的 Python 运行时，请勿删除


三、常见问题
----------------------------------------------------------------------
Q: 双击 start.bat 一闪而过 / 报错
A: 右键 start.bat → 以管理员身份运行 不一定有用，先双击 doctor.bat 看自检结果。
   最常见的原因是：没有解压直接双击（zip 里运行）、或者没写权限。

Q: 浏览器没有自动打开
A: 手动打开浏览器访问 http://127.0.0.1:8765 即可。

Q: 提示端口被占用（address already in use）
A: 程序会自动换一个空闲端口，并把这行打印在窗口里：
     Web 编辑器： http://127.0.0.1:8766
   直接用打印出来的那个地址即可。
   想固定端口：双击 edit-config.bat，把 TELEMSG_UI_PORT 改成别的值；
   想找出谁占着 8765：在命令行执行 netstat -ano | findstr :8765。

Q: 发送时提示 chat not found / 找不到会话
A: 机器人还没有加入目标频道。打开频道 → 管理 → 管理员 → 添加这个机器人，
   并勾选「发布消息」权限。私有频道要填 -100 开头的数字 ID。

Q: Windows Defender / 杀毒软件报警
A: 打包版里的 python.exe 是 Python 官方的 embeddable 运行时（来自 python.org），
   未做任何修改。误报可以忽略，或把本文件夹加入白名单。

Q: 怎么让同事也能访问
A: 用 edit-config.bat 把 TELEMSG_UI_HOST 改成 0.0.0.0，
   同时**务必**设置 TELEMSG_UI_PASSWORD（用户名固定是 telemsg），
   然后在防火墙里放行对应端口。


四、把程序发给别人
----------------------------------------------------------------------
把整个 TeleMsgCreator-*-win64 文件夹打包成 zip 发给对方，
对方解压后双击 start.bat 即可，无需安装任何东西。

注意：不要把自己填好 Token 的 .env 一起发出去 —— 那等于把机器人账号给别人。
分发前请删除 .env 和 data\ 目录。
