TeleMsgCreator（macOS 版）使用说明
======================================================================

一、启动
----------------------------------------------------------------------
双击 TeleMsgCreator 目录里的可执行文件（或在本目录执行 ./TeleMsgCreator）。
浏览器会自动打开 http://127.0.0.1:8765，第一次会弹出引导，按提示填入 Bot Token。

**本程序自带 Python 运行时，你的 Mac 不需要装 Python。**
想卸载，直接删掉整个目录即可。

二、首次运行被系统拦截
----------------------------------------------------------------------
因为安装包没有做 Apple 签名，首次打开可能提示「无法打开，因为开发者无法验证」。
解决办法任选其一：

  · 右键点图标 → 打开 → 在弹窗里再点「打开」；
  · 或者执行： xattr -dr com.apple.quarantine ./TeleMsgCreator

三、命令行用法
----------------------------------------------------------------------
打包版就是一个可执行文件，参数与原版一致：

  ./TeleMsgCreator                      # 启动 Web 编辑器
  ./TeleMsgCreator doctor               # 环境自检
  ./TeleMsgCreator send -c @ch --text hi --button "点我|https://example.com"
  ./TeleMsgCreator --help               # 全部命令

四、数据放在哪
----------------------------------------------------------------------
数据库、上传的媒体、日志都在当前工作目录下的 data/。
建议固定在一个专用目录里启动，避免每次换目录导致数据分散。
